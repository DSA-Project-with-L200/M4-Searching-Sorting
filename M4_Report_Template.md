# M4 Searching & Sorting Engine — Report

## 1. Introduction
M4 implements the Searching & Sorting Engine for the UG Campus Dispatch
& Optimization System. The module contains Linear Search, Binary Search,
Selection Sort, Insertion Sort, Merge Sort and Quick Sort.

## 2. Algorithms Implemented

### Linear Search
Checks records sequentially until the requested record is found or the
end of the array is reached.

### Binary Search
Searches a request-ID-sorted array by repeatedly dividing the search
range in half.

### Selection Sort
Repeatedly finds the smallest element in the unsorted section and moves
it to its correct position.

### Insertion Sort
Builds a sorted section by inserting each new record into its correct
position.

### Merge Sort
Divides the array into smaller sections, recursively sorts them and
merges the sorted sections.

### Quick Sort
Uses a pivot to partition the array and recursively sorts the partitions.

## 3. Dispatch System Application
The algorithms can organize dispatch records by request ID, timestamp,
distance and verification status. This supports dispatch-record
management and searching.

## 5. Complexity Analysis

| Algorithm | Time Complexity | Space |
|---|---|---|
| Linear Search | O(n) | O(1) |
| Binary Search | O(log n) | O(1) |
| Selection Sort | O(n²) | O(1) |
| Insertion Sort | O(n²) | O(1) |
| Merge Sort | O(n log n) | O(n) |
| Quick Sort | O(n log n) average; O(n²) worst | O(log n) average |
